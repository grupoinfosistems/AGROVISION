🚀 Cómo Embeber este Widget en Chiaway.com (Producción)

Para integrar el widget de AgroVisión en cualquier tienda o página web de Chiaway, simplemente agregue el archivo CSS y el script al final de su página antes del cierre de </body>:

<!-- 1. Estilos del Widget AgroVisión --> <link rel="stylesheet" href="https://cdn.chiaway.com/widgets/agrovision/agrovision-widget.css"> <!-- 2. Script del Widget con conexión a Spring Boot 3.3 --> <script src="https://cdn.chiaway.com/widgets/agrovision/agrovision-widget.js"></script> <script> AgrovisionWidget.init({ apiUrl: 'http://localhost:8080', // URL de su backend Spring Boot buttonText: 'Diagnóstico de Cultivo AI' }); </script>
